\doxysubsection{Detailed Description}
Domínio que armazena e valida a senha de um usuário. 

Regras do formato válido:
\begin{DoxyEnumerate}
\item deve ser composta por 5 caracteres;
\item cada caractere deve ser alfanumérico;
\item deve ter pelo menos uma letra e um dígito. 
\end{DoxyEnumerate}
