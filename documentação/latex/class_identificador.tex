\doxysubsection{Detailed Description}
Domínio que representa um identificador de entidade. 

Regras do formato válido:
\begin{DoxyEnumerate}
\item possui exatamente 6 caracteres;
\item os três primeiros caracteres são letras maiúsculas ou minúsculas;
\item os três últimos caracteres são dígitos. 
\end{DoxyEnumerate}
