\doxysubsection{Detailed Description}
Interface de serviço de cartões de atividade. 

Provida pelo módulo MSQU. Corresponde aos serviços 16 a 26 da especificação. Todos os métodos retornam false quando o serviço não pôde ser realizado. Durações são expressas em minutos.
