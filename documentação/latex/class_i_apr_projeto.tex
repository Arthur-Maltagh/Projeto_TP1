\doxysubsection{Detailed Description}
Interface de apresentação do módulo de projetos. 

Provida pelo módulo MAPR e usada pelo módulo MAIC. A partir de um projeto, o usuário acessa os quadros por meio de \doxylink{class_i_apr_quadro}{IApr\+Quadro}.
