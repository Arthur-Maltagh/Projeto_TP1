Detailed Description

Interface de serviço de quadros.

Provida pelo módulo MSQU. Corresponde aos serviços 11 a 15 da especificação. Todos os métodos retornam false quando o serviço não pôde ser realizado.

virtual bool ISerQuadro::atualizar ( const Quadro & quadro)
pure virtual

Atualiza os dados de um quadro.

O identificador não pode ser alterado. A atualização é recusada se o novo limite for menor que o número atual de cartões em FAZENDO.

Parameters
quadroNovos dados, com o identificador do quadro.
Returns
false se o quadro não existe ou se o novo limite é menor que o WIP atual.
