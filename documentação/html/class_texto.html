Detailed Description

Domínio que representa e valida um texto, como uma descrição.

Regras do formato válido:

  1. texto não vazio com até 30 caracteres;
  2. cada caractere pode ser letra, dígito, espaço em branco ou sinal de pontuação (vírgula, ponto e vírgula, ponto, dois pontos, ponto de interrogação ou ponto de exclamação);
  3. um sinal de pontuação não é seguido por outro sinal de pontuação;
  4. o primeiro caractere é letra maiúscula;
  5. o último caractere é ponto.
