Detailed Description

Controladora de apresentacao do modulo de autenticacao (MAAU).

Realiza a interface IAprAutenticacao. Pede email e senha ao usuario, valida o formato dos dados digitados e consulta o servico de autenticacao pela interface ISerAutenticacao.
