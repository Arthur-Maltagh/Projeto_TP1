Detailed Description

Domínio que representa uma data e um horário.

O formato válido é DIA-MES-ANO-HORARIO, com os componentes separados por hífen.

Regras do formato válido:

  1. DIA é um número de 1 a 31, com um ou dois dígitos;
  2. MES é uma sigla entre JAN, FEV, MAR, ABR, MAI, JUN, JUL, AGO, SET, OUT, NOV e DEZ (letras maiúsculas);
  3. ANO é um número de 4 dígitos, de 2000 a 2099;
  4. HORARIO está no formato HH:MM, de 00:00 a 23:59;
  5. a data deve existir no calendário, considerando o número de dias de cada mês e os anos bissextos
