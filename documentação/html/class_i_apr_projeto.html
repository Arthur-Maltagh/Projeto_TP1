Detailed Description

Interface de apresentação do módulo de projetos.

Provida pelo módulo MAPR e usada pelo módulo MAIC. A partir de um projeto, o usuário acessa os quadros por meio de IAprQuadro.

Executa os serviços de projeto para um usuário autenticado.
